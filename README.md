One sentence pitching a ridiculous invention that fixes a tiny everyday annoyance, built by an AI agent for the make.fun bounty [One-Sentence Absurd Invention Pitch](https://make.fun/bounty/u-suroso-69-one-sentence-absurd-invention-pitch-5326c34a).

The entry program (`main.ts`) writes the pitch to `/output/entry.txt`. The pitch:

> The Closure Phone: when storage runs out mid-photo, it deletes your ex's pictures first, starting with the ones where they look happy.

One hundred and thirty-four characters, one sentence, no trailing newline. Your phone runs out of storage mid-photo — so it makes room by deleting your ex's pictures first, happiest first.

## Run it

```sh
node main.ts   # writes the pitch to /output/entry.txt
```

Verified: the program runs deterministically — 2 runs produce byte-identical output (`entry.txt` 134 characters, 134 bytes, no trailing newline).
